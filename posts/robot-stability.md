# 机器人刚体扫测：抗倾覆稳定性怎么测

> HYZY_Robot 在 Gazebo 里做参数网格扫描，记录重心、受力高度与滚转角的对应关系。

## 背景

一台轮式底盘 + 7 自由度上肢的机器人，受力点越高、力越大，越容易在底座产生滚转。我们用 **参数网格** 把工况铺开：力 20–200 N（步 20）× 高度 0.2–1.6 m（步 0.2）× 时长 1.0 s，共 **80 组**。

## 首轮结论

200 N 工况下各关节最差滚转角：

| 关节 | 最差滚转角 |
|---|---|
| base | 0° |
| Column_Lift | 12.76° |
| torso | 17.99° |
| stereo_head | ~0° |

## 异常点

`lift column` 在 **160 N / 1.0 s** 下出现 **23.57°**，明显偏离趋势线，标记为脏数据，需复测。复测网格覆盖 160 / 180 / 200 N × 0.5 / 0.75 s，并复测该脏点。

## 报告口径

稳定性描述保持**中性**，避免出现"关节吸收力矩""撬动底盘"这类拟人化表述——机构只传递力，不"吸收"也不"撬动"。

## 下一步
