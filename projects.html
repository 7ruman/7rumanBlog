如何把全部项目完整复制到另一台电脑

  1. 在另一台电脑上安装 git，并登录你的 GitHub 账号（7ruman），或配置好该账号的 SSH 密钥 / 访问令牌。
  2. 对每张卡片点 复制，在终端粘贴 git clone … 即可拉取完整源码。
  3. 这些仓库都是 私有（卡片上的 🔒 标记）：只有登录 7ruman 账号、获得授权的电脑才能 clone，其他人访问会返回 404 —— 这就是你要的访问权限。

提示：CUDA / torch 等超大安装包、编译中间产物已从仓库排除（体积与 GitHub 限制原因），在另一台电脑按原方式重新安装/编译即可。
